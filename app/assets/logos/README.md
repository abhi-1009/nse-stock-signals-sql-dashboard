# Optional company logos

The dashboard shows a coloured ticker badge for each stock. To show real logos instead, save each
logo here as a square-ish PNG (JPG or SVG also work) with exactly these file names:

bajaj_auto.png · eicher_motors.png · hero_motocorp.png · infosys.png · tcs.png · tvs_motors.png

Missing files simply fall back to the badge. Company logos are trademarks: use them only with
permission or under the owner's brand-use terms, and credit the source.
